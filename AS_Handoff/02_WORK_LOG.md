# 작업 이력 (시간순)

## Phase 1: 게임 개발 (index.html)

### 핵심 시스템 구현
- 1280x720 Canvas 2D + DOM 하이브리드 게임
- Wave 방어전: 6 일반 Wave + 1 보스 Wave = 총 7 Wave
- 발키리 플레이어: WASD 이동, 자동 검 투척 공격
- 스킬 2종: Shift=바람질주(cd:3s), E=성스러운충격파(cd:18s) — 독립 쿨다운
- 가호 게이지: 시간 경과로 감소, 보주(orb) 수집으로 회복, 0%시 수문 HP 감소
- 건설 자원 3등급 (일반/희귀/에픽) 드랍 시스템

### GC 발키리 이펙트 파이프라인 구축
**캡처**: Unity URP ScreenCapture 방식 (`EffectCaptureValkSk1.cs`)
- Play Mode 진입 → 씬의 모든 카메라/Canvas/MonoBehaviour 비활성화
- 마젠타(#FF00FF) 크로마키 배경 카메라로 캡처
- 512×512 Game View 해상도, 30fps

**처리**: Python 스프라이트 시트 생성 (`make_fx_sprites.py`)
- 크로마키 제거 → RGBA 투명 처리
- **origin-centered 방식**: Unity 원점(0,0)이 프레임 중앙(256,256)에 정확히 위치하도록
  → 기존 tight_crop 방식의 오프셋 문제 해결

**적용**: `VALK_SK1_ANIMS` 상수 + `playValkSprite()` 함수
- 3종 이펙트: valk_sk1_main (75프레임), body (60프레임), weapon (60프레임)
- 프레임 크기: fw:512, fh:512 (origin-centered)
- 표시 크기: main=460×460, body=320×320, weapon=320×320
